# SJTV

SJTV LIVE — a simple web M3U player, built by Muse. Watch world news from publicly fetched iptv-org GitHub playlists, or load any public .m3u playlist by link, file, or paste.

Live page: https://sjshayk.github.io/sjtv/

The Sample World News list lives in this repo at `playlists/sj-world-news.m3u`:
https://sjshayk.github.io/sjtv/playlists/sj-world-news.m3u

Follow: [sjshayk on X](https://x.com/sjshayk) · [@sjshayk on Threads](https://threads.net/@sjshayk)

## Copyright

The channels in the Sample World News list are free public streams published by their respective broadcasters, compiled from public sources including the iptv-org channel lists. SJTV doesn't host or own any of these streams — all rights remain with their broadcasters.
